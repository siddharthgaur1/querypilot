# LLM backends for the full natural-language mode are OPTIONAL and kept out of the
# core install so the keyless demo deploys cleanly (one of them fails to build on
# the host's Python 3.14, which aborted the whole install). The app guards both
# imports, so their absence just means demo mode. For live NL→SQL locally, install
# whichever you want:
#   pip install "anthropic==0.116.0"     # then set ANTHROPIC_API_KEY
#   pip install "ollama==0.6.2"          # then run a local Ollama daemon

# Schema-aware RAG (rag/) is also OPTIONAL, same reasoning: sentence-transformers
# pulls in torch, which is exactly the kind of heavy/fragile build dependency the
# keyless demo is designed to avoid. Every rag/ module guards these imports and
# rag.prompt_builder falls back to the old full-schema prompt when they're
# missing (or when retrieval finds nothing), so the app runs identically without
# them -- just without retrieval. To enable RAG locally:
#   pip install "chromadb==1.5.9" "sentence-transformers==5.6.0"
